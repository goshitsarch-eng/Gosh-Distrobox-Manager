# Gosh Distrobox Manager

A modern, cross-platform GUI for managing [Distrobox](https://distrobox.it/) containers. Built with Flutter and Rust.

## What It Does

Gosh Distrobox Manager gives you a visual way to work with Distrobox containers. You can create, clone, start, stop, and remove containers without touching the terminal. The app includes a built-in terminal emulator so you can drop into any container with a single click.

Beyond basic container management, you can browse and export applications from your containers to your host system, manage packages using whatever package manager the container has (apt, dnf, pacman, zypper, and others), and keep track of resource usage like CPU and memory.

The app also handles backups through snapshots. Create a snapshot before making changes, and restore it later if something goes wrong. You can export entire containers to tar archives for backup or sharing.

Everything runs with real-time output streaming, so you can see exactly what's happening during long operations like container creation or package installation.

## Building

You'll need Flutter SDK (3.x+), the Rust toolchain, and `flutter_rust_bridge_codegen` v2. You'll also need Distrobox installed with either Podman or Docker as the container runtime.

```bash
git clone https://github.com/goshitsarch-eng/Gosh-Distrobox-Manager.git
cd Gosh-Distrobox-Manager
flutter pub get
flutter run -d linux
```

If you modify the Rust API, regenerate the bindings with `flutter_rust_bridge_codegen generate`.

### Release Build

To create a release build:

```bash
flutter build linux --release
```

The release build ends up at `build/linux/x64/release/bundle/gosh_distrobox_manager`.

### System-Wide Installation

To install the application system-wide with proper desktop integration (app launcher icon, taskbar icon, etc.):

```bash
# Build the release version
flutter build linux --release

# Install to /usr/local (requires sudo)
cd build/linux/x64/release/bundle
sudo cmake --install . --prefix /usr/local

# Or install to ~/.local for user-only installation
cmake --install . --prefix ~/.local
```

After installation, the application will:
- Appear in your application launcher (GNOME Activities, KDE Kickoff, etc.)
- Show the correct icon in the taskbar when running
- Be accessible via the command `gosh_distrobox_manager`

The installation includes:
- Desktop file at `share/applications/io.github.gosh_distrobox_manager.desktop`
- Icons in various sizes at `share/icons/hicolor/`
- Automatic icon and desktop file cache updates

**Note for Wayland users:** The application ID is `io.github.gosh_distrobox_manager`, which should properly match the window to the desktop file for correct taskbar icon display.

## Project Structure

The Flutter UI lives in `lib/` with state management in `providers/` and screens in `screens/`. The Rust backend is in `rust/` where `api.rs` defines what's exposed to Dart and `backends/` contains the actual Distrobox, Podman, and Docker integration logic.

Don't edit anything in `lib/src/rust/` or `rust/src/frb_generated.rs` as these are generated by flutter_rust_bridge.
